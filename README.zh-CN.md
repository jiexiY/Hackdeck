# HACKdeck

[English](README.md) | [简体中文](README.zh-CN.md) | [Español](README.es.md)

HACKdeck 是一个公开的多语言平台，用于追踪经过验证的黑客松、Build Week 以及大型 AI 和科技公司的开发者项目。它通过一条连贯的时间线展示机会，帮助开发者比较活动日期、申请截止日期、地点、参与资格、活动形式、奖金和当前状态。

**在线网站：** [hackdeck-app.vercel.app](https://hackdeck-app.vercel.app/)

## 主要功能

- 收录经过验证的公司、大学、全球、远程和 Build Week 项目
- 使用连贯且可拖动的时间线，并按时间顺序排列活动卡片
- 按主办方、地点、远程参与、活动日期、截止日期、奖金、参与资格、活动形式和状态筛选
- 查看活动详情及官方或主办方来源链接
- 提供英文、简体中文和西班牙文界面
- 将收藏的黑客松保存在浏览器本地
- 通过 JSON 导出和导入进行可移植备份
- 无需账户或注册

## 在本地运行

环境要求：Node.js 20+ 和 pnpm。

```bash
pnpm install
pnpm dev
```

在浏览器中打开 Vite 输出的本地网址。

## 验证与构建

```bash
pnpm validate:data
pnpm build
```

## 活动数据

经过验证的活动数据位于 `src/data/events.js`。只有在公司官方页面或活动主办方来源确认后，活动才会被收录。被监测的公司只是发现目标，并不会因为出现在监测名单中就自动成为活动。

更新活动数据时：

1. 使用官方或主办方来源核实日期和活动详情。
2. 去除重复的活动 ID 和来源网址。
3. 将已经结束的活动从公开数据中归档。
4. 确保 `feedMeta.sourceCount` 与 `sourceCatalog` 保持一致。
5. 运行上方的数据验证和正式构建命令。

## 收藏与隐私

收藏的黑客松通过本地存储保留在访问者的浏览器中。HACKdeck 不要求创建账户，也不会上传收藏数据。访问者可以导出 JSON 备份，并在其他浏览器或设备上导入。

## 来自创作者的话

HACKdeck 目前向所有人开放，不需要登录或注册。我希望它保持简单易用，让每个人从第一次点击开始就能获得价值。如果有足够多的人感兴趣，未来我可能会加入登录和注册系统，以提升安全性，并以更安全的方式支持跨设备保存信息。任何此类变化都会在推出前清楚说明。
